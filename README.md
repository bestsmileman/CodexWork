# CodexWork

아주와 코호가 함께 사용하는 로컬 업무 공간입니다.

- 로컬 기준 폴더: `C:\Users\Administrator\CodexWork`
- GitHub: https://github.com/bestsmileman/CodexWork
- 일상 사용: 바탕화면의 **Codex 업무 탐색기** → 간이보기 / 전체보기

## 폴더

| 위치 | 용도 |
| --- | --- |
| `memory/` | 협업 인계와 프로젝트 기준 |
| `chat-studio/` | 기존 마루 로컬 프로그램 |
| `projects/sites-workspace/outputs/` | 매뉴얼·업무 탐색기·결과물 |
| `projects/sites-workspace/work/` | 제작 도구와 사이트별 게시 원본 |

## 실행

- 업무 탐색기: `projects/sites-workspace/outputs/Codex-Explorer.cmd`
- 웹 매뉴얼: `projects/sites-workspace/outputs/Start-Codex.cmd`
- 마루: `chat-studio/start-maru.cmd`

웹 매뉴얼은 http://127.0.0.1:8787/ 에서 이용합니다.
마루는 http://127.0.0.1:4317/ 에서 이용합니다.

## Git 기록 범위

이 저장소는 검토한 코드·설명서·협업 문서를 추적합니다. 전체 PC 백업이 아닙니다.
개인 대화 저장본, 로그인 정보, 키, 실행 로그, 임시 자료와 미디어는 제외합니다.
Sites의 세 게시 체크아웃은 각자 Git 기록을 유지하므로 이 저장소에 중첩 저장소로 추가하지 않습니다.
이전 Documents/Codex 작업 위치의 outputs와 work는 현재 폴더로 연결되는 호환용 정션입니다.

파일 변경은 자동 업로드되지 않습니다. 검토 후 커밋하고 GitHub로 전송합니다.
