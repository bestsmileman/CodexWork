# 발주 · 납품 양식

2026-11-06 확정 초안 · 작성 젠스. 역할(아주 아이템·비용 / 코호 발주·검수 / 젠스 제작·납품) 아래에서 **코호가 발주하고 젠스가 납품하는 접점**의 형식.
발주는 7칸, 납품은 9항목. 앞의 7칸은 코호가 채우고, 뒤의 9항목은 젠스가 채워 돌려준다.

## 1. 발주 (코호 → 젠스)

| # | 칸 | 내용 | 예 |
|---|---|---|---|
| 1 | 숏·자산 | 숏 번호 또는 자산 이름(인물 시트 등) | `03-A` |
| 2 | 길이·해상도·화면비 | 만들 영상의 실행 조건 | `5초 / 720p / 9:16` |
| 3 | 시작 프레임 | 파일 이름 + 버전. 없으면 `없음(텍스트 시작)` | `03-A 시작 프레임 v2` (768×1360) |
| 4 | 승인 크레딧 상한 | 아주가 승인한 총액 | `418` |
| 5 | 포함 횟수 | 그 상한에 들어 있는 생성 횟수. 넘으면 새 승인 | `1회` |
| 6 | 승인 근거 | 아주 승인 메시지 번호·링크 | `아주 8858xxx` |
| 7 | 제작 지시 · 검수 기준 링크 | 어떤 동작·카메라·금지사항으로 만들고, 무엇을 통과로 볼지 | `docs/샘플-3클립-계획.md` 2절 03-A · 3절 |

한 줄로 쓰는 형태:

```
발주 03-A / 5초·720p·9:16 / 시작 03-A 시작 프레임 v2 / 상한 418 · 1회 / 승인 아주 8858xxx / 지시·기준 docs/샘플-3클립-계획.md 2절 03-A·3절
```

7번이 가리킬 문서는 고정한다. 숏 설계·연속성은 `docs/jeonghee_pilot_기획안_v5.md` 3·5절, 숏별 고정 조건과 검수 기준은 `docs/샘플-3클립-계획.md` 2·3절, 프롬프트 원문은 원 PDF(2) 17쪽 숏 명세. 새 숏이면 발주 때 기준 링크를 새로 지정한다.

## 2. 실행 전 확인 (젠스)

1. 상한이 현재 잔액보다 크면 실행하지 않고 발주자에게 돌려보낸다.
2. 실행 직전 견적을 다시 확인한다(`--estimate`). 상한을 넘으면 실행하지 않고, 실제 견적을 붙여 회신한다. 상한 이내면 그대로 실행한다.
3. 모델·티어가 지시와 다르거나 지정이 없으면 실행 전에 한 번 확인한다. 임의 변경 금지.
4. 상한 안의 횟수를 다 쓰면 재생성은 새 발주다.

## 3. 납품 (젠스 → 코호)

| # | 항목 | 무엇을 |
|---|---|---|
| 1 | 결과 파일 | 파일 이름 · 크기 · sha256 · 전달 경로 |
| 2 | 실제 차감 | 실행 응답의 차감값. 견적과 다르면 **둘 다** 적는다 |
| 3 | 모델·티어 | 예: `fal-ai/bytedance/seedance-2.0` · standard |
| 4 | 실행 설정 | 길이·해상도·화면비 + 모델 기본값과 다르게 준 값 |
| 5 | 입력 프롬프트 | 실제 전송한 원문 그대로(언어 불문). 요약·의역 금지. 내부 변환된 프롬프트를 조회할 수 없으면 그 한계를 명시 |
| 6 | 참조 | 입력 이미지 파일 이름·버전·sha256. 여러 장이면 전부 |
| 7 | 실행 ID | 실행 추적·재조회용 task_id |
| 8 | 상태·시각 | 성공/실패, 시작·완료(UTC). 실패면 오류 코드 |
| 9 | 검수용 소견 | 내가 먼저 본 것(관통·복제·얼굴 일치 등). **판정은 코호** |

영상 파일은 채널에 첨부하고, 9항목은 채널 한 덩어리로 넘긴다. 코호가 이를 `docs/숏별-제작기록.md` 한 줄과 「프롬프트·산출물 위치」 표로 옮긴다.

시드·내부 파라미터는 실제 도구 응답에 제공될 때만 기록하고, 제공되지 않으면 `미제공`으로 적는다. task_id는 실행 추적, SHA-256은 파일 동일성 확인에 사용한다. 프롬프트·참조·실행 ID가 있어도 동일 영상 재생성이 보장되지는 않는다.

## 4. 검수와 재생성

1. 통과·보완 판정은 코호. 확인 방식(정상 속도 연속 재생 / 스틸만 / 원본 프레임 대조)을 함께 적는다.
2. 보완이면 원인 한 줄을 받아 새 발주를 낸다. 횟수가 리셋되고 승인 근거도 새로 붙는다.
3. 같은 조건으로 다시 뽑는 것도 승인 횟수에 포함된다.

## 5. 산출물 보관

- 영상은 채널 첨부로 납품한다. 저장소에는 파일명·크기·SHA-256·실행 ID와 납품 메시지 링크를 남긴다. 코호는 전달받은 원본을 로컬에 보관한다. 별도 요청 없이 MP4를 Git에 커밋하지 않는다.
