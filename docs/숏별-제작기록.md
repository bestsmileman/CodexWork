생성 1회 = 표 한 줄. 같은 숏을 다시 뽑으면 **버전**을 올리고 시도 번호를 붙인다(`v1·t2` = 1번째 버전의 2번째 시도).
줄에는 짧은 값만 넣고, 긴 것(프롬프트 전문·산출물 파일)은 표 아래 「프롬프트·산출물 위치」에 링크로 둔다.

읽는 규칙

- **버전·시도** — 처음이 `v1·t1`. 프롬프트나 참조를 바꿔 다시 뽑으면 `v2·t1`, 같은 조건으로 재시도하면 `v1·t2`.
- **실행 조건** — `5s / 720p / 9:16`처럼 길이·해상도·비율만. 모델 기본값과 다르게 준 값이 있으면 같이 적는다.
- **참조** — 입력 이미지의 이름과 버전(`정희 시트 v1`, `03-A 시작 프레임 v2`). 여러 장이면 `+`.
- **승인** — `docs/결정과-승인.md`의 해당 행 날짜(`11-02 위임`, `11-01 결정`)를 적어 원장과 연결한다. 승인 없이 실행한 줄은 `없음`으로 적고 사유를 남긴다.
- **검수** — `확인 방식`과 `판정`을 같이 적는다. 방식: `스틸만` / `연속 영상까지` / `원본 프레임 대조`. 판정: `통과` / `보완` / `미검수`.
- 아직 만들지 않은 줄은 `미제작`으로 두고, 선행 조건이 있으면 결과 칸에 적는다.
