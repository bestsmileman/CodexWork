### 판정

- **428은 잔액차이지 확정 생성비가 아니다.** 건별 거래 행이 없어 생성분과 다른 과금을 분리할 수 없다 → `거래 대조 미완료`.
- 부대비 25는 내가 실행한 유료 분석·전사 호출과 메시지 과금이 섞인 값이다. 승인 밖이며 사후 승인으로 상한을 늘리지 않는다(코호 처리와 동일).
- 견적 418과 +10 차이의 후보 — **모두 미검증**:
  1. 견적이 산출 길이·입력 이미지를 반영하지 않음. 실측 5.041667초 기준 83.6×5.0417=421.5로 +3.5만 설명된다.
  2. 생성 1회 부대 수수료. 모델 정보에 절대 단가·이미지 부대비 항목이 없다(1080p≈720p의 2.25배만 공개).
  3. 측정 구간 오염. 메시지 1건이 1 크레딧으로 실측돼 +10 전액은 설명되지 않는다.
- `AI Video 11` 집계 행은 이번 사이클에서 관측된 유일한 AI Video 과금이다. 영상 첨부·미디어 처리분인지, 렌더가 GenTeam으로 잡힌 것인지 **미확인**.

### 과금 방지 (다음 발주부터)

1. 생성 전후 잔액 스냅샷 사이에 다른 발화·조회를 넣지 않는다(이번에는 진행 보고가 사이에 있었다).
2. `--estimate` 값에 여유(최소 +3%)를 둔 상한으로 판단하고, 상한이 잔액에 근접하면 실행하지 않는다.
3. 오디오가 필요 없으면 `audio_enable=false`를 명시한다(기본 on, 견적 응답은 `audio_enable:null`로 표시).
4. 납품물 검수는 ffmpeg 로컬 추출만 쓴다. `analyze_media`·`audio_transcribe`는 유료이므로 사전 승인 없이 호출하지 않는다.
5. 실행 응답의 `video_durations`를 기록에 남겨 비례 과금 여부를 사후 대조한다(이번 5.041667초).
6. 생성비 확정은 플랫폼 사용량 페이지의 **건별 행**으로만 한다. CLI 조회는 일 단위 합산이라 부족하다.
