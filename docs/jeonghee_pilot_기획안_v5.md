## 4. 인물·의상

- 5인: 정희, 서연, 수진, 다은, 지우
- 정희 의상: **7부 소매**. 조리 중에는 **걷은 상태**가 정상 — 03-A·03-B는 v2의 걷은 높이와 접힘을 그대로 유지한다. 장면마다 소매 상태를 통일할 필요는 없다(같은 옷, 같은 사람).
- 기준 시트와 스틸의 소매 차이는 **드리프트가 아니라 동작 상태 차이**로 본다.

## 5. 동작·연속성 및 검수 원칙

1. **03-A 시작:** v2 유지. 왼손은 볼을 고정, 오른손은 된장이 얇게 묻은 시래기 일부를 이미 들어 올린 상태. 새로 집거나 된장을 바르는 단계로 되돌아가지 않는다.
2. **접기:** 들고 있는 재료를 볼 안쪽으로 부드럽게 뒤집어 넣어 섞는다. 두 번의 작은 접기를 목표로 하되 횟수를 맞추려는 급가속·과장된 누르기보다 숙련된 흐름을 우선한다. 가닥 수를 기계적으로 세기보다 분량·줄기 결·재료의 연속성을 확인한다.
3. **물리:** 손가락·관절, 접촉·해제, 재료의 처짐과 무게감, 손과 재료의 관통·복제·소실, 볼 고정 상태를 동작 전 구간에서 확인한다. 의도된 접촉·가림 자체를 결함으로 판단하지 않되, 가림 속 변형을 무조건 정상으로 간주하지도 않는다.
4. **카메라·배경:** 전 숏 고정. 03-A에서 지우는 뒤에서 조용히 손을 관찰한다. 지우 시트 미확보 시 v2와의 연속성은 볼 수 있지만, 승인된 독립 기준 대비 얼굴 일치 판정은 유보한다.
5. **01:** 눈맞춤은 01-A에서만. 01-B는 얼굴 없는 손 클로즈업이며 다은 손이 정희 손등 위에 이미 얹힌 상태로 시작한다. 접촉음을 새 접촉이 일어난 것처럼 과장하지 않는다.
6. **02·04:** 그릇 직접 밀기 없음. 쟁반 착지·손 떼기, 접시 내려놓기, 먹기·삼키기·미소 순서가 인과에 맞아야 한다. 소품 수량·소유·좌우 배치와 01↔04 공간을 유지한다.
7. **의상:** 같은 7부 옷의 조리 중 걷음으로 해석한다. 다른 장면은 시간·행동 연결에 맞추며, 소매 차이를 전부 오류 또는 전부 정상으로 단정하지 않는다.
8. **전달·음향:** 화면에 추가 제목·자막·로고 없음. 대사·음악 없이 생활음만. 접촉음은 실제 접촉 시점에 개별 동기화하고 일괄 2~4프레임 선행하지 않는다.
9. **판정:** 정상 속도 연속 재생으로 리듬·감정을 보고, 의심 구간은 저속·프레임 단위로 확인한다. 프레임 추출만 했다면 연속 재생 감상으로 보고하지 않는다.
