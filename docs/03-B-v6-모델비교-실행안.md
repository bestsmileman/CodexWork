## 0. 이 문서의 성격

- **모델 비교 시험**이다. 손 동작은 이번 시험에서 **제외**이며 '해결됨'이 아니다.
- 목적은 **같은 연출 의도를 어느 후보가 더 적합하게 표현하는지 평가**하는 것이다. '모델만의 효과 입증'이 아니다.
- "남은 변수는 모델뿐"·"1회로 원인을 가른다"고 쓰지 않는다.
- **결론 표기 규정**: 두 모델 모두 기준 미달이면 **"이번 조건에서 두 결과 모두 채택 기준 미달, 원인 미확정"**으로 적는다. '모델 문제가 아니라 연출 문제'로 단정하지 않는다 — 모델별 1회는 생성 편차·시작 스틸·프롬프트 해석의 영향을 분리하지 못한다.
- 얼굴 컷이므로 파일명·숏 번호를 **03-B**로 쓴다.

## 2-2. 시선 축 — 현재 스틸 기준 설계 (미확정 사항 포함)

- **확인된 사실**: 03-B 시작 스틸의 지우는 눈과 얼굴이 **화면 오른쪽 아래**를 향하고, 머리도 이미 약간 기울어 있다(스틸 직접 확인). 03-A는 다른 카메라 위치의 컷이라 '정희가 화면 왼쪽'이라는 정보를 03-B로 그대로 옮길 수 없다.
- **철회**: 이전 개정판의 "시선 목표 = 화면 왼쪽"은 철회한다. 왼쪽 끝으로 눈만 옮기라고 하면 시작 방향을 가로질러 시선이 렌즈를 통과할 위험이 있다.
- **개정 설계**: 기존 **화면 오른쪽 아래 작업 지점**에서 출발해, **같은 화면 오른쪽의 정희 얼굴 높이에 있는 하나의 고정 지점**으로 눈을 조금 올린다. '가장자리'가 아니라 **렌즈 축을 벗어난 한 점**을 보게 한다.
- **미확인**: 02·04 컷과의 촬영 배치도·실제 스틸을 확보하지 못해 **최종 촬영 축은 검증되지 않았다.** 이 설계는 현재 스틸을 유지한다는 전제의 연출 권고이며, 컷 연결에서 상대가 납득되는지는 편집 단계 검수 항목이다.
