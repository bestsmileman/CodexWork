## 03-B 시선·머리 — 정정판 (2026-11-10, 0dae982 철회)

**철회**: 0dae982의 "화면 왼쪽 실측 확정", "자기 눈높이보다 살짝 위", "정면에서 5~10°·고개 3~5°" 수치는 모두 뺀다. 스틸 한 장으로 방향을 °로 확정할 근거가 없다. 코호가 다시 본 결과는 **오른쪽 아래 → 같은 오른쪽의 정희 얼굴 방향**이고(9419367), 이는 v6 개정 2·3판의 시선 설계와 같다 — 그쪽으로 맞춘다.

**문구에 쓰는 것 / 쓰지 않는 것**

| 항목 | 처리 |
|---|---|
| 시작 시선 | 아래 작업 지점 — 참조 이미지와 같은 방향 |
| 상승 목표 | 정희가 있는 **방향**의 한 고정점. 카메라 축 밖, 렌즈 아님 |
| 높이 | **단정하지 않는다.** "정희 얼굴이 자기 눈높이보다 위"라는 근거 없음 → 시선은 자기 눈높이 정도에서 멈춘다 |

| 깜박임·호흡 | 별도 수행 과제로 넣지 않는다(눈에 띄지 않을 만큼만) |
| 화면 좌/우 단어 | 프롬프트에 쓰지 않는다 — 한 장으로 좌우를 확정할 수 없고, 참조 이미지가 공간 관계를 이미 들고 있다 |
