- **길이 불일치 주의**: Veo 3.1은 4/6/8초만 지원해 **5초 생성이 불가**하다. Kling 5초와 Veo 6초는 생성 길이까지 다른 비교이며, 편집에서 잘라도 조건이 같아지지 않는다.
- **생성 길이 ≠ 편집본 길이**: Veo 6초로 생성해도 실제로는 앞뒤를 잘라 **최대 5.0초만 사용**하므로 33초 조립 길이는 바뀌지 않는다. 두 값을 따로 적는다.
- 기본안: **Kling 5초 단독 1회(924)** — 5초 생성·5초 사용, 한 모델 1회 승인 범위.
- 대안: Veo 6초 단독(924, 6초 생성 → 최대 5초 사용 / 생성 조건이 달라 비교 조건 불일치) / 길이 맞춘 2종(Kling 6초 1,109 + Veo 6초 924 = 2,033, 두 모델 각각 승인).

- 판정: v6 개정 4판 5절 **2층**(기본 오류 검수 필수 + 핵심 감정 3개).
- **두 모델 모두 미달이면 결론은 "이번 조건에서 두 결과 모두 채택 기준 미달, 원인 미확정"** — '모델 문제가 아니라 연출 문제'로 단정하지 않는다. 모델별 1회는 편차·시작 스틸·프롬프트 해석을 분리하지 못한다.
