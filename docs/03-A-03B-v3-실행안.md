초점만 옮기는 안은 폐기한다. 코호 지적대로 초점을 지우로 옮겨도 손은 화면에 남아 "손 노출 1.5~2초"가 되지 않고, 같은 프레임에서 배경 인물 얼굴은 화면 대비가 작아 표정이 읽히지 않는다. **컷**으로 넘긴다.

편집 배분(기본안 A): 03-A 사용 **1.5~2.0초** + 03-B 사용 **6.0초** = 7.5~8.0초. 03 = 8초를 정확히 채우려면 2.0 + 6.0을 쓴다. 손 노출을 1.5초로 더 엄격히 묶는 안 B는 03-B를 8초로 생성(669)해야 하고 총액이 1,090으로 올라간다(7절 대안).
