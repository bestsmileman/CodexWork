마루 주소: http://127.0.0.1:4317/
사용할 때 start-maru.cmd를 더블클릭한 뒤 접속합니다.
작업을 완료하거나 중지한 후 stop-maru.cmd로 종료합니다.
마루는 기존 로컬 도구이며, 현재 GenTeam 협업 방향과는 구분합니다.
인계 문서는 작성 당시 기록입니다. 현재 연결 상태를 보장하지 않습니다.
대화 백업은 마루 설정의 '전체 대화 백업'을 사용합니다.
state.json과 state.json.bak은 직접 수정·삭제하지 않는 편이 좋습니다.

다른 채팅에서 작업을 이어갈 때 사용할 문장:
"C:\Users\Administrator\CodexWork의 AGENTS.md와
 memory\GENTEAM_HANDOFF.md를 먼저 읽고 이어가줘."
※ 이 파일들이 다른 모든 채팅에 자동 적용되지는 않습니다.

5. 막힐 때 확인할 것
====================
매뉴얼 주소가 안 열림 → 바탕화면의 'Codex 매뉴얼' 다시 실행
마루 주소가 안 열림   → chat-studio\start-maru.cmd 실행
메모·할 일이 안 보임  → 작성했던 주소를 같은 브라우저·프로필에서 열기
어디서 이어갈지 모름  → 공통 폴더의 AGENTS.md + memory\GENTEAM_HANDOFF.md

경로를 이용하려면 전체 경로를 복사해 Windows 탐색기 주소창에
붙여넣고 Enter를 누르세요. 텍스트에 적힌 경로는 자동 실행되지 않습니다.
