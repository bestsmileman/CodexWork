# 마루 Chat Studio

마루는 설치된 Codex를 그대로 이용하는 독립적인 로컬 작업 공간입니다. Codex 프로그램·설정 파일을 수정하거나 복제하지 않습니다. 이 대화창을 열어 둘 필요도 없습니다.

## 실행

`C:\Users\Administrator\CodexWork\chat-studio\start-maru.cmd`를 더블클릭하세요. 마루 서버를 백그라운드로 실행하고 기본 브라우저에서 `http://127.0.0.1:4317/`을 엽니다. 이미 실행 중이면 같은 서버를 이용합니다.

`index.html` 경로는 그대로입니다. 파일을 직접 열면 화면과 로컬 기록을 볼 수 있지만 실제 Codex 대화는 위 주소에서 이용해야 합니다. 설치된 Node.js와 로그인된 Codex가 필요합니다. 추가 npm 패키지나 별도 API 키는 필요하지 않습니다. Codex 이용은 기존 계정의 사용량과 정책을 따릅니다.

종료하려면 `stop-maru.cmd`를 실행하세요. 진행 중인 작업이 있으면 먼저 마루에서 중지하거나 완료해 주세요. 종료 대상은 마루가 실행한 서버이며 기존 Codex 앱은 그대로 유지됩니다.

## 할 수 있는 일

- 실제 Codex와 대화, 실시간 답변 표시, 모델 선택, 작업 중지
- 작업 폴더에서 Codex를 통한 파일 읽기·작성·명령 실행
- 실행 과정과 결과 확인, 수정한 텍스트 파일 미리보기·복사·내려받기
- 대화별 메모, 답변을 메모에 담기, 대화 제목 변경과 즐겨찾기
- 대화 제목·본문·메모 검색 (`Ctrl+K`), 새 대화 (`Ctrl+Shift+O`)
- 코드·목록·표가 포함된 Markdown 답변, 코드 복사, 답변·대화 내보내기
- 텍스트 파일 첨부·드래그 앤드 드롭: 최대 8개, 개당 256KB, 합계 512KB
- 전체 대화 JSON 백업·불러오기, 밝은 화면·밤의 화면·시스템 테마, 글자 크기 설정
- PC와 좁은 화면에서 사용할 수 있는 반응형 화면
- Codex의 작업 승인 요청, 질문, 연결 서비스의 기본 입력 폼 표시

## 저장과 연결

대화와 메모는 브라우저 저장소와 `chat-studio\.maru\state.json`에 저장됩니다. 직전 저장본은 `state.json.bak`에 남습니다. 서버 기록이 있으면 서버 기록을 우선 불러옵니다. 대화 삭제는 마루의 목록에서만 삭제하며 Codex 자체 기록은 삭제하지 않습니다.

여러 창에서 동시에 편집하면 덮어쓰기를 막고 새로고침을 안내합니다. 필요한 내용은 설정의 전체 대화 백업으로 보관할 수 있습니다. 연결이 끊겨도 Codex의 작업은 계속될 수 있습니다. 다시 연결하면 현재 대화의 최근 기록을 확인합니다.

마루는 현재 작업 폴더 `C:\Users\Administrator\CodexWork`와 `workspace-write` 샌드박스를 사용합니다. 추가 접근이 필요한 경우 Codex의 승인 요청을 표시합니다. 모든 파일 변경에 매번 승인 창이 나타나는 것은 아니며, Codex의 적용 정책을 따릅니다. 접근은 PC 내부 `127.0.0.1`로 제한하며 외부 사이트의 API 요청을 거부합니다.

## 현재 범위

실제 Codex 대화와 로컬 파일 작업을 지원합니다. Codex 앱의 모든 기능이 마루 화면에 구현된 것은 아닙니다. 이미지·PDF 첨부, 음성 대화, 이미지·영상 생성 전용 화면, 플러그인 설치·로그인 관리, 다른 기기로의 동기화는 아직 포함하지 않습니다. 설치된 도구의 실행 가능 여부는 기존 Codex 설정·로그인·해당 도구의 요구 사항에 따라 달라집니다. 이 대화창의 전용 도구나 대화 맥락을 자동으로 복사하지 않습니다.

## 검증

`node ui-smoke.cjs`는 별도의 Chrome/Edge 프로필로 실제 브라우저 검증을 실행합니다. 실제 Codex 요청 1회와 검증용 문서 `examples\연결_확인.md` 생성이 포함됩니다. 결과와 화면 캡처는 `.maru\qa`에 저장합니다. 기존 브라우저 프로필은 이용하지 않습니다. `--visual-only` 옵션은 AI 요청 없이 화면만 검증합니다.

`node server-smoke.cjs`는 로컬 접근 제한, 저장 충돌 방지, 작업 폴더 경계와 기존 Codex 설정 파일의 무변경 여부를 확인합니다. 설정 비교에는 검증 전에 `.maru\qa\config-before.sha256`에 기록한 지문을 사용합니다.

공식 연결 인터페이스: [Codex App Server](https://learn.chatgpt.com/docs/app-server).
